# bigalex95.github.io

Personal portfolio site of Alibek Erkabayev: a single-page, dark-only Jekyll site with plain hand-written CSS and a tiny JS file for the mobile nav toggle.

## Run locally

```sh
bundle install
bundle exec jekyll serve
```

## Deploy

GitHub Pages builds the repo root of `master` with Jekyll. There is no other build step.

## Editing content

- `_data/experience.yml`, `_data/education.yml`, `_data/projects.yml`, `_data/skills.yml`: the section content.
- `_config.yml`: title, description, links, CV path, analytics id.
- `_includes/` and `assets/css/main.css`: markup and styling.

The original theme was Neumorphism by Long Do (MIT).
